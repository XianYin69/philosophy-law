# branch（分支库）

本目录存放「哲学法律」的执行流程与判断分支。

## 内容

- [`流程/`](流程/流程.md)：主干流程，7 个节点（知识检索、出处核验、条文引用、
  法域比较、现状分析、独立思考、输出审查）。
- 两个推理能力已**提升为与本体平级的子技能**：
  [现状分析/](../现状分析/SKILL.md)、[独立思考/](../独立思考/SKILL.md)
  （各含 SKILL.md＋branch/＋resistance/）。
  本目录下 `流程/现状分析/`、`流程/独立思考/` 保留为**流程索引节点**，
  指向子技能细则，主干链接不悬空。

## 分支判定

| 情形 | 走向 |
|---|---|
| 条目命中且已核验 | 条文引用 → 输出审查 |
| 条目命中但 `verified: partial` | 出处核验补证 → 条文引用（标 `待核`） |
| 条目缺失 | 知识检索记录缺口 → 联网补卡或如实拒答 |
| 用户要个案结论 | 转介提示（不作法律意见），仅给学理分析 |
| 用户要立场 | 独立思考子技能全六步，禁止跳步 |
| 用户要「现状如何」 | 现状分析子技能六必答项，标时效与不确定性 |

## 约定

- 文件夹名＝流程名（中文流程名，脚本一律英文名）。
- 每个 .md ≤ 50 行；节点间链接必须可达。
