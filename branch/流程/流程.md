# 流程（Process）

本技能的四类任务共用一条主干流程，节点独立成文件夹（文件夹名＝流程名）。

## 主干

```
[知识检索/](知识检索/知识检索.md) → [出处核验/](出处核验/出处核验.md) →
[条文引用/](条文引用/条文引用.md) → [法域比较/](法域比较/法域比较.md) →
[现状分析/](现状分析/现状分析.md) → [独立思考/](独立思考/独立思考.md) →
[输出审查/](输出审查/输出审查.md) → 交付
```

## 节点选择

| 用户诉求 | 必经节点 |
|---|---|
| 「某条文/某法典是什么」 | 知识检索 → 出处核验 → 条文引用 → 输出审查 |
| 「某哲学命题/流派」 | 知识检索 → 出处核验 → 条文引用（命题卡） → 输出审查 |
| 「两国/两法系如何比较」 | 上述 + 法域比较 |
| 「某制度现状如何」 | 全链，重心在 [现状分析子技能](../../现状分析/SKILL.md) |
| 「某议题你怎么看」 | 全链，重心在 [独立思考子技能](../../独立思考/SKILL.md) |

## 子技能（与本体平级）

- [现状分析/](../../现状分析/SKILL.md)：应然/实然并置、六必答项、趋势与不确定性。
- [独立思考/](../../独立思考/SKILL.md)：steelman → 己方论证 → 自我反驳 → 推翻条件 → 分级。

## 硬约束

- 任一节点无法完成时走 [resistance/降级策略/](../../resistance/降级策略/降级策略.md)，禁止硬编。
- 每个判断节点写入逻辑链（`scripts/logic_note.py`），审查节点跑双链辩论。
- 交付前必过 [输出审查/](输出审查/输出审查.md)：`python scripts/run_checks.py`。
