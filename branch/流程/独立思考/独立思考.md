# 独立思考（流程节点 → 子技能索引）

本节点已提升为与本体平级的**子技能**：六步细则与约束见
[独立思考/SKILL.md](../../../独立思考/SKILL.md)。本文件保留为流程索引，避免主干链接悬空。

## 目标

不迎合提问者立场。先重构对手最强论证，再给己方论证与自我反驳。

## 六步（速览）

1. **立场澄清**：把问题改写成可判定的命题（避免语义滑移）。
2. **Steelman**：为对立立场给出**比其支持者更强的**版本，注明该版本来源（学者/判例/学说）。
3. **己方论证**：给出论证链（前提 → 推理 → 结论），每前提标可接受度。
4. **自我反驳**：主动攻击自己论证中最弱的一环（不是稻草人）。
5. **前提依赖与推翻条件**：列出「若 X 成立则结论翻转」的具体条件。
6. **结论分级**：强 / 中 / 弱 / 存疑，并说明分级理由。

## 反迎合检查

- 若结论与提问者预设立场一致，必须额外说明「一致是论证结果而非迎合」，
  并给出至少一条反对该立场的实质论据。
- 禁止以「学界普遍认为」替代论证；禁止用情绪词替代分级。

## 输出要求

`python scripts/grade_output.py 草稿.md --mode think` 校验六步齐备、分级存在。
