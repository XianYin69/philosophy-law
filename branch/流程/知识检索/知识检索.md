# 知识检索

## 目标

把用户问题映射到知识树上的**具体节点**，而不是凭记忆直接作答。

## 步骤

1. 判定域：法条（law）／哲学（philosophy）／两者交叉（如「自然法」）。
2. 定位层级：法典 → 编/章/条；哲学家 → 代表文本 → 命题。
3. 用 `python scripts/search_entries.py --q "<关键词>" --domain law` 检索
   [asset/](../../../asset/asset.md) 下的 YAML 条目，取回 `id / source / era / jurisdiction`。
4. 命中不足时：先查 [asset/index/coverage.md](../../../asset/index/coverage.md) 的拓扑前沿，
   明确告知「本技能库该节点尚未建卡」，再决定是否联网补卡。

## 输出

一份候选条目清单（含 `id` 与置信标记），供 [出处核验/](../出处核验/出处核验.md) 使用。

## 禁止

- 禁止跳过检索直接给条文号；禁止把「我印象中」当作出处。
- 禁止用条目 `gist` 冒充原文（要原文须走核验）。
