# 出处核验

## 目标

确认「条文号／年代／法域／效力状态」四要素有可追溯来源，无法确认者显式标注 `待核`。

## 核验顺序（由强到弱）

1. **官方文本**：立法机关/政府公报（如 gesetze-im-internet.de、legifrance.gouv.fr、
   eur-lex.europa.eu、全国人大网）。
2. **公版权威译本/校勘本**：Avalon Project、Loeb、Packard Humanities、ctext.org。
3. **学术参考**：SEP、IEP、Cambridge/Stanford 史卷、权威教科书。
4. **二手转述**：只可用于「学界通说」表述，**不得**当作原文引证。

## 判定规则

- 四要素齐备且有一手来源 → `verified: yes`。
- 有来源但版本/条文号存疑（如古法典条数各家不一）→ `verified: partial` + 正文标 `待核`。
- 无来源 → 不得输出具体条文号/年份，只给「要旨级」描述并说明缺口。

## 输出

条目卡补 `refs[]`、`verified`、`last_checked` 三字段；`python scripts/check_sources.py` 通过。
