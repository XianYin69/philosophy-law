# 输出审查

## 目标

交付前的最后一道闸门：条目合规、引用可核、结论分级、无越权意见。

## 九项标准

1. 法条卡五要素齐备（出处/条文号、年代、法域、效力状态、要旨）。
2. 哲学卡四要素齐备（代表文本、核心命题、流派、后世批评）。
3. 无编造出处：不确定处已标 `待核`，且 `待核` 项未参与结论承重。
4. 二手转述未被当作原文引用。
5. 跨法域比较已注明语境差异。
6. 现状分析含应然/实然区分、时效与不确定性标注。
7. 独立思考含 steelman、自我反驳、前提依赖、结论分级。
8. 敏感议题只作学理与制度分析，附「咨询执业律师」提示。
9. 悬空链接 = 0（`python scripts/lint_refs.py`）。

## 执行

```
python scripts/run_checks.py
```

任一 FAIL → 记中断（`scripts/logic_note.py interrupt`）→ 修复 → 重跑；
同一错误重复 3 次即降级（见 [resistance/降级策略/](../../../resistance/降级策略/降级策略.md)），
达 10 次熔断并求助用户。
