# 现状分析（流程节点 → 子技能索引）

本节点已提升为与本体平级的**子技能**：细则、输出结构与约束见
[现状分析/SKILL.md](../../../现状分析/SKILL.md)。本文件保留为流程索引，避免主干链接悬空。

## 目标

把**规范文本**与**当下事实**并置，区分「应然（Sollen）」与「实然（Sein）」。

## 六必答项（速览）

1. 规范层：现行有效条文及其效力状态（含最近修订年份）。
2. 事实层：实际运行数据/执法司法实践（须给来源与统计口径）。
3. 落差：应然与实然的偏离点及可解释机制。
4. 争议焦点：学说对立（列出双方代表文本）、立法/司法争议节点。
5. 利益相关方：国家、市场、个人、群体（含弱势方）及其诉求。
6. 可比法域参照：至少一个，附 [法域比较/](../法域比较/法域比较.md) 的语境差异说明。

## 输出要求

- 趋势判断须标 **强度**（强/中/弱/存疑）与**依据**。
- 每条事实须标 `信息时效`（截至日期）与 `不确定性`（高/中/低）。
- 数据缺口如实写「本技能库无该节点数据」，不得估算充数。

## 禁止

- 禁止提供个案法律意见；结尾须提示「具体案件请咨询执业律师」。
