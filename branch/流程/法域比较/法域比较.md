# 法域比较

## 目标

跨法域对照同一制度，输出**语境差异**而非「谁更先进」的结论。

## 步骤

1. 先各自定位功能等价物（functional equivalent），再比较名称。
   例：英美 trust ≠ 大陆法「信托」概念；德国 Mitbestimmung ≠ 中国职工代表大会。
2. 标注四项语境差异：法源层级（成文/判例）、解释方法（文义/历史/目的/体系）、
   诉讼构造（对抗/纠问）、效力范围（联邦制/单一制）。
3. 指明「不可比」之处并说明原因（宗教法、习惯法的规范结构常与成文法不同层）。
4. 结论只到「差异描述 + 成因假设」，优劣判断须转 [独立思考/](../独立思考/独立思考.md)。
