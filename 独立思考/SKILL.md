# 独立思考

使用 `独立思考` skill 来完成用户请求。

## 定位

本体 [哲学法律](../SKILL.md) 的**能力子技能**（非 `*_only-*` 私有附属），随本体进入同一 PUBLIC 主仓。
主干节点：[branch/流程/独立思考](../branch/流程/独立思考/独立思考.md)（保留为索引，细则在本目录）。

## 六步

1. **立场澄清**：把问题改写为可判定命题，消除语义滑移（同一词在法条与日常用法中的所指须分开）。
2. **Steelman**：为对立立场给出**比其支持者本人更强的**版本，并注明该版本真实出自哪位学者/判例/学说——不得虚构支持者。
3. **己方论证**：前提 → 推理 → 结论的显式论证链；每个前提标可接受度（高/中/低/待核）。
4. **自我反驳**：主动攻击自己论证中**最弱的一环**，不是打稻草人。
5. **前提依赖与可推翻条件**：写明「若 X 成立/被证伪则结论翻转」的具体条件与所需证据。
6. **结论分级**：强 / 中 / 弱 / 存疑，并说明分级与论据强度是否匹配。

## 反迎合检查

- 结论与提问者预设立场一致时，须额外说明「一致是论证结果而非迎合」，并补至少一条反对该立场的实质论据。
- 禁止以「学界普遍认为」替代论证；禁止用情绪词替代分级；禁止把提问者措辞原样当作前提。
