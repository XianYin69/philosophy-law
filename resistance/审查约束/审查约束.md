# 审查约束

## 九项标准（对应 [输出审查](../../branch/流程/输出审查/输出审查.md)）

法条五要素、哲学四要素、无编造、二手不充原文、比较注语境、
现状含应然/实然与时效、独立思考含 steelman 与分级、敏感议题附转介提示、悬空链接=0。

## 自动化对应

| 标准 | 脚本 |
|---|---|
| 法条/哲学要素 | `scripts/validate_entries.py` |
| 出处与 `待核` | `scripts/check_sources.py` |
| 悬空链接与依赖 | `scripts/lint_refs.py` |
| 结论分级与六步 | `scripts/grade_output.py` |
| 一键全检 | `scripts/run_checks.py` |
| 路径锚定（与 CWD 无关） | `scripts/_corpus.py`（`__file__` 基准＋`--root`） |

## 人工复核（脚本无法判定者）

- 「要旨是否忠实于条文」——须回看 T1/T2 文本。
- 「steelman 是否真的更强」——须能举出该论证的真实支持者。
- 「分级是否与论据强度匹配」——防止强论据弱分级或反之。

## 熔断

同一 FAIL 重试达 10 次 → 停止并求助用户；达 3 次 → 先走
[降级策略](../降级策略/降级策略.md)，不得原样重试。
