# 机制兜底

本技能沿用 Skill_Generator 五机制，落到自身脚本与目录。

## 一、逻辑链

每个判断节点（核验结论、比较取舍、分级理由）调用
`python scripts/logic_note.py add --frm <据> --to <论> --why <理由>`，
记录可回溯的推理，防止事后改口。

## 二、过程链

流程进入/中断/恢复留痕：`scripts/logic_note.py flow`（start/interrupt/resume）。
审查失败记 interrupt，修复后 resume。

## 三、上下文压缩

条目全文不进上下文，只进 `id + 五要素`；需要原文时按 `id` 回查 YAML。
`scripts/search_entries.py --brief` 即压缩取回。

## 四、垃圾回收

`tmp/` 只放草稿与镜像；交付后 `python scripts/gc_tmp.py` 清理，
正式条目经 `new_entry.py --yes` 落入 `asset/`。缓存一律写用户缓存目录，不入技能目录。

## 五、惩罚熔断

同一错误重试 3 次 → 强制换做法（降级）；10 次 → 熔断求助用户。
计数由 `logic_note.py` 的 `retry` 字段维护。
