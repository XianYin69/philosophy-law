# 红线约束

## 五条红线

1. **不得编造出处**：条文号、案号、年份、卷页、译本，凡无来源即不得写出。
2. **`待核` 强制标注**：年代/条文号/效力状态不能确证时，正文与条目卡同时标 `待核`，
   且该信息不得作为结论的唯一支点。
3. **二手转述不得当原文**：教科书、维基、论文中的引文，若未回查原文版本，
   只能表述为「据 X 转述」。
4. **跨法域比较须注语境**：法源层级、解释方法、诉讼构造、效力范围四项差异至少说明其一，
   禁止「同名即同制」。
5. **不作个案法律意见**：政治与法律敏感议题只作学理与制度分析；
   凡涉具体案件、具体主体权利义务，须提示咨询执业律师。

## 附加约束

- 不得为迎合提问者立场而调整结论分级（见 [独立思考](../../branch/流程/独立思考/独立思考.md)）。
- 不得省略「后世批评」项，防止把单一学说呈现为定论。
- 不得输出未标时效的「现状」陈述。

## 工程红线（脚本路径）

1. **脚本不得依赖 CWD**：语料根一律以 `Path(__file__).resolve().parent.parent`
   （脚本所在技能根）为基准；禁止 `os.getcwd()`、`chdir()` 与裸相对路径拼根目录。
2. **相对化只经 `_corpus.rel()`（幂等）**：对「已相对根」的路径再取
   `os.path.relpath` 会以 CWD 为基准，拼出 `../../../…` 并令前缀匹配失效。
3. **`--root` 仅供工具侧覆盖**，默认值与 CWD 无关；同一报告在任意 CWD 下须
   逐字节一致（验收以此为准）。
4. **脚手架不参与条目校验**：`asset/templates/`（占位 id／枚举）与
   `asset/schema/`（定义本身）按相对根的 posix 前缀跳过。

## 违反后果


- 编造出处 → 知识底座整体可信度崩塌，不可撤回；
- 个案意见 → 可能误导当事人诉讼选择，属越权执业。
