# systems（法系与判例传统）

非成文法传统的知识节点。每节点在 `systems.yaml` 中一卡。

## 覆盖

| 传统 | 关键机制 | 卡 id 前缀 |
|---|---|---|
| 英国普通法 | 遵循先例、ratio decidendi / obiter、令状制度史 | `law.system.commonlaw.*` |
| 衡平法 | 信托、禁令、良心救济、1875 司法法融合 | `law.system.equity.*` |
| 美国联邦与州法 | 联邦制、司法审查、双重法院体系、联邦规则 | `law.system.uslaw.*` |
| 欧盟法 | 直接效力、优先性、条例/指令/决定 | `law.system.eulaw.*` |
| 伊斯兰法系 | 沙里亚、菲格赫、四大法学派、法源方法论 | `law.system.islamic.*` |
| 印度法 | 达摩论、属人法、印度教法典化、宪法基本结构 | `law.system.indian.*` |
| 习惯法 | 原住民法秩序、ILO 169、UNDRIP、南非习惯法 | `law.system.customary.*` |
| 混合法域 | 魁北克、路易斯安那、南非、苏格兰、以色列 | `law.system.mixed.*` |
