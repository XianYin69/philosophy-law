# 现状分析分支（细则）

按议题类型给出必答清单与取证口径。数据卡：[reasoning 推理卡](../../../asset/reasoning/current-state.yaml)。

## 一、制度运行现状

- 规范文本：条文号 + 效力状态 + 最近修订。
- 运行数据：官方统计/司法文书/评估报告，标口径与截至日期。
- 落差机制：激励、资源、程序、观念四选一以上。

## 二、争议焦点

- 学说对立：列双方**代表文本**（非人名标签），标 T2/T3 出处。
- 制度节点：立法条款冲突、司法解释分歧、管辖竞合。

## 三、利益相关方

国家（治理成本）、市场（交易成本）、个人（权利与救济）、群体（含弱势方诉求）。
每方须写「诉求 + 可用的制度通道」，不得只写立场标签。

## 四、可比法域参照

至少一个参照法域；须写移植条件与语境差异，禁止「他国如此故当如此」的推论。

## 五、趋势判断与时效

- 强度：强 / 中 / 弱 / 存疑，并写依据。
- 每条事实标 `信息时效` 与 `不确定性`（高/中/低）。
- 缺口如实声明，不估算充数。
