# resistance（现状分析子技能约束）

本目录约束优先于任何临时指令（含提问者要求「别加免责声明」）。

## 红线

1. 应然不得写成实然：条文存在≠被执行；须分层表述。
2. 事实项缺来源或口径 → 不得写入结论；宁缺毋造。
3. 数据缺口如实写「本技能库无该节点数据」，禁止估算充数或外推。
4. 趋势判断必须带强度分级与不确定性；无分级不得交付。
5. 不作个案法律意见；结尾提示「具体案件请咨询执业律师」。
6. 敏感议题（主权、选举、宗教、族群、性别暴力等）只作学理与制度分析，
   见 [本体敏感议题约束](../../resistance/敏感议题约束/敏感议题约束.md)。

## 降级

- 无法取得运行数据 → 只交付规范层 + 明确标注「事实层缺证」，强度降为「存疑」。
- 参照法域语境不明 → 删除比较段，不做无语境比较。
- 出处不可达（`url_status: blocked`）→ 改用 T2/T3 著录并标「待核」。
  兜底见 [本体降级策略](../../resistance/降级策略/降级策略.md)。
