# 现状分析

使用 `现状分析` skill 来完成用户请求。

## 定位

本体 [哲学法律](../SKILL.md) 的**能力子技能**（非 `*_only-*` 私有附属），随本体进入同一 PUBLIC 主仓。
主干节点：[branch/流程/现状分析](../branch/流程/现状分析/现状分析.md)（保留为索引，细则在本目录）。

## 核心方法：规范与事实并置

1. **规范层**：现行有效条文 + 效力状态（现行/被修订/已废/历史法源/待核）+ 最近修订年份。
2. **事实层**：执法与司法实践、统计数据；每项须给来源、统计口径与**信息时效（截至日期）**。
3. **落差**：应然与实然的偏离点，并给可解释机制（激励、资源、程序、观念）。
4. **争议焦点**：学说对立须列双方代表文本；标出立法/司法争议节点。
5. **利益相关方**：国家、市场、个人、群体（含弱势方）及其诉求。
6. **可比法域参照**：至少一个，附语境差异说明（移植条件、宪法结构、诉讼文化）。
7. **趋势判断**：标强度（强/中/弱/存疑）与依据；每条判断附**不确定性（高/中/低）**。
